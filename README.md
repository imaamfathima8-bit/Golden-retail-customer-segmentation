# Golden Retail – Customer Segmentation

Golden Retail – Customer Segmentation is a machine-learning project that uses K-Means clustering to group retail customers based on behavioural and purchasing patterns. The objective is to identify meaningful customer segments that can support more targeted marketing decisions.

## Key Features

- Customer data preprocessing and feature preparation
- K-Means clustering for customer segmentation
- Cluster analysis and interpretation
- Visualisation of customer segments
- Business-oriented recommendations for targeted marketing

## Business Value

Customer segmentation can help marketing teams understand different customer groups, personalise offers, prioritise campaigns, and improve targeting decisions. This project demonstrates how unsupervised machine learning can translate customer data into practical marketing insights.

## How to Run

1. Clone the repository.
2. Install the required packages.
3. Open the Jupyter Notebook.
4. Run the cells from top to bottom.

```bash
git clone [https://github.com/imaamfathima8-bit/Golden-retail-customer-segmentation.git](https://github.com/imaamfathima8-bit/Golden-retail-customer-segmentation.git)
cd Golden-retail-customer-segmentation
pip install -r requirements.txt
```
